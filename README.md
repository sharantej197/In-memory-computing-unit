# In-memory-computing-unit
This repository explores In memory computing architectures using crossbar based designs that merge storage and computation within the same hardware structure. The work demonstrates how resistive crossbar arrays can be utilized to perform parallel operations directly inside memory, reducing data movement overhead. 

## 2x2 cross bar
Implemented 2x2 cross bar array using resistors.The resistance of them act like a weights in a neural network,In a circuit developed with mosfets we can alter the resistances of MOS according to the weights of the networks.
